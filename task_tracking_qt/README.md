# Task Manager 2.0

## Запуск

Нужны Python 3.10+ и `PyQt6`.

```bash
cd task_tracking_qt
uv run --with PyQt6 app.py
```

Если `uv` не используется:

```bash
python -m pip install PyQt6
python app.py
```

## Основные возможности

- `QMainWindow`, `centralWidget` и layouts;
- поле названия, поле описания, список `QListWidget` и статус с количеством задач;
- предупреждение при пустом названии;
- очистка полей после добавления;
- подтверждение перед очисткой всего списка;
- счётчик символов названия через `textChanged`;
- единый QSS-блок для полей, списка и кнопок.

## Бонус: JSON и редактирование

Задачи сохраняются в `tasks.json` рядом с `app.py`. При следующем запуске файл
читается автоматически. Добавление, изменение выбранной задачи, удаление и
очистка списка сразу обновляют файл.

Чтобы изменить задачу, выделите её в списке, двойным кликом загрузите значения
в форму, поменяйте нужные поля и нажмите «Изменить выбранную».

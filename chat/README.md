# Чат
```bash
cd chat
python3 server.py
python3 client.py
```

Клиент ждёт имя не более 15 секунд. Если имя не введено, он печатает сообщение
и завершает работу. После подключения поддерживаются команды:

| Команда | Действие |
| --- | --- |
| `/list` | Показать подключённых пользователей. |
| `/nick <новое_имя>` | Сменить имя без переподключения. Сервер не разрешит занятое или пустое имя. |
| `/quit` | Отключиться от сервера. |
| Любой другой текст | Отправить сообщение в чат. |

## Протокол

Каждое сообщение состоит из заголовка `!HI`, затем из команды и payload:

1. `H` — длина команды в байтах;
2. `I` — длина payload в байтах;
3. команда в UTF-8;
4. payload.

Команда ограничена 64 байтами, payload — 10 МиБ. Поэтому `ERROR` передаётся
полностью, а не обрезается до четырёх байтов. Поддерживаемые команды: `JOIN`,
`TEXT`, `LIST`, `NICK`, `QUIT` и ответ сервера `ERROR`.

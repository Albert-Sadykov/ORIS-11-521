# Список фильмов

Личный каталог фильмов на Flask и SQLite.

## Запуск

Из корня репозитория выполните команды с Python 3.11 или новее и `uv`.

```bash
cd flask_movies
uv run app.py
```

Откройте http://127.0.0.1:5000/. Если порт занят, Flask можно запустить на другом порту командой `uv run flask --app app run --port 5001`.

## Работа с приложением

- Зарегистрируйтесь, чтобы получить личный каталог с тремя исходными фильмами.
- Чтобы добавить запись, нажмите «Добавить фильм» и заполните название, режиссёра и описание.
- Нажмите на название фильма, чтобы открыть описание и увидеть режиссёра.
- На странице фильма можно отредактировать или удалить запись. При ошибке в форме редактирования введённый текст сохраняется. После успешных изменений откроется страница фильма, а после удаления — список.
- Для проверки доступа зарегистрируйте второй аккаунт. У каждого аккаунта свой каталог. Запрос к фильму другого пользователя возвращает `404`.

## Дополнительные функции

1. Поиск по названию. Введите часть названия и нажмите Применить.
   Поиск игнорирует регистр букв. Пустая строка показывает все фильмы.
2. Сортировка. Выберите По названию и нажмите Применить. Можно
   отсортировать весь список или результаты поиска. По умолчанию фильмы
   отображаются в порядке добавления.

## Выполненные задания

1. База SQLite. При запуске приложение создаёт файл `instance/movies.sqlite3`. В `schema.sql` описаны таблицы `movies`, `directors` и `users`.
2. Постоянное хранение. Фильмы, режиссёры и аккаунты загружаются из БД. Три исходных фильма добавляются в базу только при регистрации пользователя. Все правки сохраняются после перезапуска.
3. CRUD. Создание, чтение, редактирование и удаление фильмов выполняются через БД. Формы проверяются на сервере. Для удаления по HTTP есть `DELETE /movies/<id>` с сессией пользователя и заголовком `X-CSRF-Token`. Кнопка удаления отправляет POST обычной HTML-формой.
4. Связанные таблицы. У режиссёра может быть несколько фильмов. Связь защищена внешним ключом. Список и страница фильма получают имя режиссёра через JOIN.
5. Пользователи. Регистрация, вход и выход используют Flask-Session. Пароли хранятся в SQLite в виде хешей. Сессии хранятся на сервере в `instance/sessions/` через CacheLib. SQL-запросы ограничивают доступ идентификатором владельца.

## Структура кода

- `app.py` запускает сервер, `application.py` собирает приложение.
- `movies.py` содержит маршруты каталога, `auth.py` — регистрацию, вход и проверку сессии.
- `db.py` содержит подключение к SQLite и запросы. `schema.sql` задаёт таблицы, внешние ключи и индекс. Приложение выполняет его при запуске, чтобы создать отсутствующие таблицы, а записи хранит в `instance/movies.sqlite3`.
- `templates/` содержит HTML-шаблоны, `pyproject.toml` — зависимости проекта для `uv`.

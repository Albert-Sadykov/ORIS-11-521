# Playlist

Класс `Playlist` для работы с музыкальными композициями.

## Запуск

Требуется Python 3.10 или новее.

```bash
cd "дз 1"
python3 playlist.py
```

## Что реализовано

- `add_song(name, duration)` — добавляет песню в плейлист;
- `remove_song(name)` — удаляет первую найденную песню по названию и возвращает `True` или `False`;
- `total_duration()` — возвращает общую продолжительность песен в секундах;
- `len(playlist)` — возвращает количество песен с помощью метода `__len__`;
- `show_songs()` — возвращает пронумерованный список песен для вывода пользователю.

Песни хранятся в списке `songs`. Каждая песня — это словарь с ключами `name` и `duration`.

# PyQt6 Менеджер задач

## Возможности

- ввод названия и многострочного описания задачи;
- выбор одного приоритета: Low, Medium или High;
- дополнительные независимые настройки: Important и Send notification;
- вывод созданной задачи в окне и в консоли;
- очистка формы кнопкой Clear;
- статус создания задачи и счётчик созданных задач.

## Использованные элементы

- `QMainWindow` — главное окно приложения;
- `QWidget` и `centralWidget` — контейнер для содержимого окна;
- `QLineEdit` — однострочное поле названия задачи;
- `QTextEdit` — многострочные поля описания и результата;
- `QRadioButton` и `QButtonGroup` — выбор одного приоритета;
- `QCheckBox` — независимые дополнительные настройки;
- `QPushButton` — создание и очистка задачи;
- `QVBoxLayout`, `QHBoxLayout`, `QGridLayout` — расположение элементов интерфейса.

## Запуск

Требуются Python 3.10 или новее и uv.

```bash
cd 08.10.2026
uv run --with PyQt6 app.py
```

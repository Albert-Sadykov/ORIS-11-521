# Многопоточный сервер задач

Консольное клиент-серверное приложение для общего списка задач.

## Запуск

Нужен Python 3.10 или новее.

В первом терминале запустите сервер:

```bash
cd 30.09.2026
python3 server.py
```

В другом терминале запустите клиента:

```bash
cd 30.09.2026
python3 client.py
```

## Команды клиента

| Команда | Действие |
| --- | --- |
| `/add <текст>` | Добавить задачу в общий список. |
| `/list` | Показать общий список задач. |
| `/done <номер>` | Отметить задачу как выполненную. |
| `/quit` | Отключиться от сервера. |

Пример списка:

```text
1. [ ] Купить кофе
2. [x] Подготовить домашку
```

## Одновременная работа клиентов

Сервер использует TCP-сокет. После каждого подключения он создаёт отдельный поток `threading.Thread`, который обрабатывает команды конкретного клиента. Поэтому один клиент может вводить команду, пока другие клиенты продолжают работать.

Все задачи хранятся в одном списке `tasks` внутри `server.py`, а не в клиентах. Поэтому задача, добавленная одним клиентом, видна всем остальным после команды `/list`.

## Синхронизация

Для списка `tasks` создан `tasks_lock = threading.Lock()`. Он используется в функциях `add_task`, `mark_task_done` и `format_tasks` через `with tasks_lock:`. Это не позволяет двум потокам одновременно изменять или читать список в момент изменения и предотвращает некорректные данные.
